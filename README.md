# ATLAS — дневник тренировок на карте

<p><a href="https://verno-dev-studio.github.io/workout-diary/"><b>&#9654; Live demo</b></a></p>

Премиальный дневник тренировок: кликните точку на интерактивной карте — и запишите пробежку или велозаезд прямо на местности. Матово-чёрный интерфейс с золотым акцентом.

## ✨ Возможности
- Тренировка привязывается к точке клика на карте (Leaflet + OpenStreetMap)
- Типы: бег и велосипед, с полями темпа/скорости, каденса/набора высоты
- Геолокация центрирует карту на пользователе
- Список тренировок синхронизирован с маркерами — клик ведёт к точке
- Данные сохраняются в localStorage и переживают перезагрузку
- ООП-архитектура (App, Workout, Running, Cycling)

## 🛠 Стек
- **JavaScript (ES6-классы)** — логика приложения
- **Leaflet** — карта и маркеры
- **Sass** — премиальная чёрно-золотая тема

## 🚀 Запуск
Откройте `index.html` в браузере — сборка не нужна.
